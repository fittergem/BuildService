# BuildService

**Welcome to BuildService - The first public and open-source plot-based freecam sandbox building system.**

**Special note:** This project is completely open-source, meaning that anyone can use the system without permissions or limitations. That being said, lot of time, thought, and effort has gone into this project, and supporting this project is always appreciated and acknowledged on our supporters page. Thank you!
