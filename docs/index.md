# BuildService

**Welcome to BuildService - The first public and open-source plot-based freecam sandbox building system.**

**Special note:** This project is completely open-source, meaning that anyone can use the system without permissions or limitations. That being said, lot of time, thought, and effort has gone into this project, and supporting this project is always appreciated and acknowledged on our supporters page. Thank you!

## Description

The BuildService project serves to provide a prebuilt, customizable, advanced, and open-source "build mode" for developers. It's goal is to minimize the time and effort developers put in to making a production game while still providing as many features as possible.

As far as BuildService features, here is a list of notable features BuildService offers:
* Plot selection system
* Save selection system
* Plot serialization and saving (Support for external DataStore solutions)
* Save loading system (Support for external DataStore solutions)
* Assignable values to objects, walls, paint, materials, etc. (Support for external economy system)
* Plot freecam
* Grid snap placement
* Smooth snapping (Interpolation between snapped positions)
* Placement in plot bounds
* Object placement
* Wall placement
* Floor placement
* Roof placement
* Window/door placement
* Room detection
* Multiple "levels" (Basements, upper floors, etc.)
* Transform tool (Scale, move along axis, etc.)
* Paint tool (Customizable coloring options for objects)
* Server validated placement

There are several additional features not listed that make BuildService even more amazing. All features are highlighted in the [documentation page](documentation.md)
